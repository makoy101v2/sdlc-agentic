# SDLC Agentic

Autonomous engineering team scaffold for Codex.

## Structure
- `chief/` orchestration and validation
- `agents/` role prompts for specialized agents
- `memory/` shared project knowledge
- `workflows/` reusable SDLC workflows
- `checklists/` validation gates
- `.github/` issue, PR, and CI templates

## Purpose
This repository provides a modular scaffold for an autonomous engineering team with a Chief Engineering Agent, a Technical Reviewer, an Engineering Auditor, and specialized SDLC agents.
